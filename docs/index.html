Apple 芯片 · macOS 14+
版本、安装包与发布说明以 GitHub 发布页为准。

  1. 1

    下载并打开安装包

    在发布页的 Assets 中选择适合 Apple 芯片 Mac 的安装包，下载后打开。

  2. 2

    退出旧版，同名替换

    将 cduyzhMediaForge.app 放入“应用程序”。已有同名应用时，先退出正在运行的旧版，再选择替换。

  3. 3

    从“应用程序”启动

    以后统一从这里打开。源码中的 build 目录是构建产物位置，不作为日常启动入口；版本可在“关于”中确认。

图形界面与终端，共用一个 App

也能融入你的命令行。

先完成上方安装，再直接调用“应用程序”里的可执行文件。

查看完整帮助

"/Applications/cduyzhMediaForge.app/Contents/MacOS/cduyzhMediaForge" --help

CLI 与图形界面使用同一份程序，更新 App 后即使用新版本。

转为实况并导入“照片”

"/Applications/cduyzhMediaForge.app/Contents/MacOS/cduyzhMediaForge" "/path/to/video.mp4"

指定封面，保存配对文件

"/Applications/cduyzhMediaForge.app/Contents/MacOS/cduyzhMediaForge" --frame-time 2.5 -o "$HOME/Desktop/LivePhotos" "/path/to/video.mp4"

将 /path/to/video.mp4 替换为你的文件路径。封面时间需位于视频时长内；指定 -o 时仅保存文件，不自动导入图库。

可复制命令到终端运行。
