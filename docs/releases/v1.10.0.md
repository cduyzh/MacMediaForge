cduyzh MediaForge 1.10.0 新增网络视频清晰度选择，并改进清晰度校验与远程解析安全。

- 在设置中选择默认的 1080P、720P、480P 或 360P，也可以在预解析卡片中调整单项。
- 哔哩哔哩、X/Twitter 与小红书解析会按所选档位优先请求可用码流；超过目标清晰度时按比例缩放。
- 系统画质上限为 1080P。缩放失败或缺少 FFmpeg 时会显示错误并保留下载的原视频。低于目标画质的来源不会放大。
- 网页状态只按 JSON 解析，不执行远程页面返回的 JavaScript。

本版本面向 Apple 芯片与 macOS 14 或更新版本，采用 Ad-hoc 签名，未经过 Apple 公证。网络解析需要 Python 3；画质缩放、去水印与部分音视频合并功能需要另行安装 FFmpeg，二者均未随应用内置。各平台可用画质受来源、登录状态和平台接口限制。
