cduyzh MediaForge 1.9.0 改善本地制作、网络提取、历史与设置界面，补齐任务反馈，并统一安装与版本识别。

- 工作区切换保留输入，主操作固定在底栏；提供空态、错误详情、取消收尾和部分成功提示。
- 安全导出配对文件，保留源视频与同名成果；修复 GIF/MOV 的参数校验、取消和失败反馈。
- 网络下载后生成 GIF、配对文件或导入照片失败时报告原因，保留已完成成果。
- CLI 失败返回非零状态；缓存后台统计，取消仅清理已登记文件。
- 网络解析验证证书与主机名，兼容 macOS 系统根证书；移除开发机器的固定路径依赖。
- 设置显示实际版本、构建号与路径。开发产物进入 `.build.noindex`；源码安装脚本备份旧副本并统一 `/Applications` 与 CLI 入口。
- 官网下载地址、CLI 引导、复制反馈和键盘交互修复。

安装：下载 DMG，将应用放入「应用程序」并替换旧版本。日常从 `/Applications/cduyzhMediaForge.app` 启动。源码升级可运行 `./scripts/install-local.sh`，它会先备份旧应用并移除本项目旧 build 副本。

支持范围：本次发布包为 Apple 芯片（arm64），macOS 14 或更新版本。采用 Ad-hoc 签名，尚无 Developer ID 签名及 Apple 公证。网络解析依赖本机 Python 3，音视频合并与去水印依赖 FFmpeg，均未随 App 内置。网络平台可用性与画质受公开链接、登录状态和平台接口限制。本次回归不包含真实照片库写入与各平台全量下载验收。

发布资源附带 SHA256SUMS.txt 和 build-info.json，便于核对下载完整性与源码提交。
