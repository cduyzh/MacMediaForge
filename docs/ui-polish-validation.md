# UI 优化验证记录

验证日期：2026-10-18。对象为 `App` 中的原生 macOS 应用。

## 实现范围

- 系统语义配色、统一字号和留白、轻描边分组、克制的强调色；共享样式位于 `MediaForgeUI.swift`。
- 主导航按需创建并保留已访问页面，隐藏页面不接收点击、快捷键或辅助功能访问。
- 本地制作补齐队列空态、文件导入摘要、失败原因、折叠调整区、输出类型对应的完成反馈与查看入口。
- 单项与批量任务共用状态管理；批量重试失败项、跳过完成项，取消收尾期间保持忙碌状态。
- 网络提取固定底部主操作，补齐输入焦点、无效输入、清空、取消收尾、错误和部分成功反馈；成果可加入本地队列。
- 小红书助手统一视觉，脚本从应用资源读取并反馈复制结果；本地接收地址不再冒充实时健康状态。
- 设置与历史记录统一分组，支持搜索无结果与筛选重置；缓存统计移至后台并合并刷新请求，慢目录不再阻塞页面。
